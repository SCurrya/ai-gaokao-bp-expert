# AI Gaokao BP Expert 展示层说明

## 1. 为什么要做展示层

这个项目如果只有真实业务链路，已经能证明系统能跑通。

但如果还想让 GitHub 展示页更容易理解，就需要一层“可讲解、可演示、可复盘”的展示层。

所以我把第二层定位为：

- 产品经理
- 程序员
- 测试

这三者不一定都是真 Agent，但非常适合展示你对产品、工程、质量的整体理解。

---

## 2. 展示层和真实业务层的关系

第一层负责把事做出来：

- 客户经理 Agent
- 数据侦察 Agent
- 策略 Agent
- 规则校验 Agent

第二层负责把为什么这样做讲清楚：

- 产品经理：讲业务设计
- 程序员：讲代码结构
- 测试：讲质量保障

这就是“双层结构”的核心价值。

---

## 3. 当前已经做好的展示层能力

你现在可以直接运行：

```bash
python scripts/showcase_roles.py --text "我是广东物理类，排位42000，普通工薪家庭，想留广东，偏计算机，不想土木"
```

它会自动输出三段内容：

1. 产品经理视角
2. 程序员视角
3. 测试视角

这很适合：

- GitHub README 展示
- 静态网页演示
- 快速理解系统结构

如果你想看“老板视角”下员工如何自己沟通，也可以运行：

```bash
python scripts/agent_boardroom.py --text "我是广东物理类，排位42000，普通工薪家庭，想留广东，偏计算机，不想土木"
```

这会输出一版内部会审 transcript，让项目更像一个真实的公司化 Agent 组织。

---

## 4. 展示层的作用

- 把主链路 Agent 的职责讲清楚
- 把展示角色和真实业务 Agent 区分清楚
- 让页面更容易被快速浏览和理解
